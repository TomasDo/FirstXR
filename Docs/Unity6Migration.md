## Compatibility Changes

- Updated Unity packages and serialized project settings; retained XR Interaction Toolkit and XR Hands versions matching the existing Samples.
- Imported TMP Essential Resources for Unity 6 and corrected UV data type assumptions in older TMP sample code.
- Rebuilt the Visual Scripting node library and refreshed the node cache generated by the old editor.
- Updated the main Gradle template to the new editor template, retaining the pinned MediaPipe `tasks-vision:1.0.0` dependency.
- Explicitly declared the Gradle namespace in the camera permission Android library; the MediaPipe library uses the current Gradle DSL and locally installed Build Tools.
- XREAL 3.1.0 uses `nrsdk.pack` for both `nr_common` and `nr_loader`. Enabled custom Gradle Properties with `android.uniquePackageNames=false` to preserve the older toolchain's compatibility behavior. Remove this setting only after upgrading the XREAL SDK and confirming that its library namespaces are distinct. See [AGP 9.0 changes](https://developer.android.com/build/releases/agp-9-0-0-release-notes).
- Build helper menus now throw on failure so command-line builds can return a failure status.
